# Library Management System in Python 📚

## Description
This is a simple console-based Library Management System built using Python Object-Oriented Programming (OOP). It allows users to view available books, borrow books, and return them, while dynamically updating the library's inventory.

## Features
* **Display Books:** View the current list of available books in the library.
* **Borrow Books:** Check out a book, removing it from the available list and adding it to the borrowed list.
* **Return Books:** Return a borrowed book, adding it back to the library's available inventory.
* **Interactive Menu:** A continuous while-loop menu for easy navigation and user interaction.

## How to Run
1. Ensure Python is installed on your system.
2. Run the script using the command: `python library.py`
3. Follow the on-screen menu choices (1-4) to interact with the library.
